# Zephyr Plugins

The curated registry of community plugins for [Zephyr](https://github.com/Prismo-Studio/Zephyr), plus the scaffolding and local test tools plugin authors use to build them.

Zephyr fetches `registry.json` from this repository to populate its plugin browser. Each registry entry points to a folder under `themes/`, `games/`, `mods/`, or `features/`.

## Repository layout

```
themes/<plugin-id>/   manifest.json + theme.css
games/<plugin-id>/    manifest.json + game.json
mods/<plugin-id>/     manifest.json
features/<plugin-id>/ manifest.json (runtime ships in Zephyr)

registry.json         generated by scripts/build-registry.mjs

examples/             starter scaffolds plugin authors copy from
preview/              static Zephyr-shaped HTML preview for themes
scripts/              registry build + validate + preview tooling
tester/               full Tauri app — slim Zephyr clone for end-to-end testing
```

## Contributing a plugin

1. Copy the matching folder out of `examples/` (or use the [GitHub template](https://github.com/Prismo-Studio/zephyr-plugin-template)) and rename it after your plugin's id.
2. Edit `manifest.json` and the entry asset (`theme.css`, `game.json`, etc.).
3. Validate locally: `pnpm validate path/to/your/plugin`.
4. Preview locally: `pnpm preview` for the HTML preview, or `cd tester && pnpm tauri dev` for the full Tauri tester (see [tester/README.md](tester/README.md)).
5. Submit a PR adding your folder under the matching type directory (`themes/`, `games/`, `mods/`, `features/`). Folder name must equal the `id` field.
6. CI runs `scripts/build-registry.mjs` after merge to regenerate `registry.json`.

## Local commands

```sh
pnpm build:registry   # walk themes/games/mods/features and rewrite registry.json
pnpm validate         # check every example + every registered plugin
pnpm validate themes/neon-pulse   # check a single folder
pnpm preview          # serve the HTML preview at http://localhost:5174
```

The HTML preview lets you drop a `theme.css` onto a Zephyr-shaped UI to see the result in any browser. The Tauri tester under `tester/` is a slim Zephyr clone — same components, same install pipeline — and gives you a real native window with a folder picker. Use the HTML one for quick palette iteration and the Tauri one for last-mile verification before opening a PR.

## Manifest reference

| field | required | notes |
| --- | --- | --- |
| `id` | yes | lowercase slug, no spaces (`a-z`, `0-9`, `-`). Must match folder name. |
| `name` | yes | display name in the plugin browser. |
| `version` | yes | semver, e.g. `1.0.0`. |
| `type` | yes | one of `theme`, `game`, `mod`, `feature`. |
| `author.name` | yes | shown on the plugin card. |
| `author.url` | optional | profile or project link. |
| `description` | yes | one or two sentences. |
| `icon` | optional | filename in your folder, an absolute URL, or an Iconify id like `mdi:palette`. Defaults to a type-appropriate Iconify icon when omitted. |
| `entry` | themes & games | filename of the asset (`theme.css`, `game.json`). |
| `package` | mods only | object with `url` and `sha256` of the mod archive. |
| `game` | mods only | slug of the target game. |
| `defaultInstalled` | features only | optional bool, defaults to `false`. |
| `removable` | features only | optional bool, defaults to `true`. |
